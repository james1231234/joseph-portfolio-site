03 / BEHIND THIS SITE

A small interface.
A bigger picture.

This site doubles as a cloud engineering project. Its AWS template defines how the application can run across two availability zones.

  1. 01

    Route

    An Application Load Balancer directs traffic to healthy instances.

  2. 02

    Serve

    EC2 instances serve the same versioned site artifact with Nginx.

  3. 03

    Scale

    Auto Scaling adjusts capacity using average CPU utilization.

  4. 04

    Measure

    A load-test script reports observed request success and latency.

○ Infrastructure is provided as deployment configuration. No live AWS deployment or uptime result is claimed.
